# 機種データ出典管理

**Project:** Juggler Analyzer  
**基準日:** 2026-10-03

## 1. 採用原則

設定推測ロジックに使う数値は、性質ごとに出典レベルを分ける。

### A. BB / RB
北電子公式の製品情報に掲載された設定別確率を採用する。

### B. ブドウ
ジャグラーの小役確率はメーカー公式の設定別数値が原則非公表であるため、解析・実戦値を「参考データ」として扱う。

- 全設定について十分な試行数の参考値が得られる場合のみ設定別適合度へ使用する。
- 一部設定しかデータがない機種は、カウンターと実測ブドウ確率の表示のみ行い、設定別適合度には加えない。
- ブドウを採用する場合もBB/RBより弱い補助証拠として重み付けする。
- 新しい信頼性の高いデータが得られた場合は、本書と `machines.js` を同じCRで更新する。

## 5. 注意

ブドウ参考値はメーカー公表値ではない。したがって、アプリ上でも「参考値」であることを明示し、設定確率として扱わない。
