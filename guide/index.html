JUGGLER ANALYZER v0.2

使い方・レビューガイド

ジャグラー実戦中に、総回転数・BIG・REG・任意のブドウ数を入力して、設定別の統計的な適合度を確認するiPhone向けツールです。

アプリを開く

最短の使い方

1. 機種を選ぶ
2. 現在の総回転数・BIG・REGを入力
3. 必要なら着席時データとブドウを入力
4. 「評価を更新」を押す
5. 設定別適合度・評価材料・ChatGPT共有を確認

ペカったときの入力

左上のネオン風 GOGO! ボタンがクイック入力です。

  1. GOGO!を押す
  2. ブドウカウンターが一時的に隠れる
  3. 総回転数がクリアされ、入力欄へカーソルが移動する
  4. 現在の総回転数を入力する
  5. BIG +1 または REG +1 を押す
  6. 回数を加算して自動で再評価する

GOGO!を押しただけではBIG/REGは増えません。総回転数を入れてから当選種別を選びます。

ブドウカウンター

画面左側の固定ボタンで、ブドウを +1 / -1 できます。入力欄の「着席後 累計ブドウ」と同期します。

ブドウを設定評価へ使うのは、十分な設定別参考データを採用している機種だけです。それ以外の機種では、数えることはできますが「参考表示のみ」になります。

評価の読み方

BIG / REG / 合算
現在の実測確率。表示は 1/xxx.x。
設定別適合度
入力データが各設定の基準値にどれだけ整合するかを相対表示したもの。
高設定寄り指数
設定別適合度から作った0〜100の相対指標。
評価材料
BIG・REG・ブドウ・試行G数を個別に確認する欄。
サンプル充足度
総回転数がどれくらい積み上がっているかの簡易目安。

設定別適合度は「設定確率」ではありません。 店舗の設定配分などの事前情報は、現在の自動判定には入っていません。

「BIG 弱め」などの意味

評価材料の「弱め」「良好」は、その項目単体の評価です。

たとえばBIGが「弱め」でも、REGが強く、設定別適合度では中間〜高設定側に寄ることがあります。1行だけで台全体を判断せず、設定別適合度と他の材料を合わせて見てください。

ChatGPTへ共有

「確認したいこと」から目的を選びます。

  • 設定再評価
  • 続行価値
  • やめ時
  • 見切りライン
  • 店舗・イベント込み信頼度
  • 前回からの変化
  • 着席価値

「追加状況」には、イベント日・投資額・残り時間・周辺台などを任意で入力できます。「選択テンプレでコピー」を押してChatGPTへ貼り付けます。

データ保存

入力途中の値や実戦履歴は、その端末・ブラウザのLocalStorageへ保存されます。通常のデプロイやページ再読み込みでは消えません。

「新しい実戦を開始」を押すと、現在の実戦入力・履歴をリセットします。

友人レビューで見てほしい点

  • 実戦中に入力しやすいか
  • GOGO! → 回転数 → BIG/REG の流れが直感的か
  • 評価結果の意味が誤解しにくいか
  • 固定ブドウカウンターが邪魔にならないか
  • 文字サイズ・ボタンサイズ・スクロール量は適切か
  • 使っていて「ここを1タップ減らしたい」という箇所があるか
